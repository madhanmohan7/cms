Welcome to **Eco**, a powerful web portal built to manage, monitor, and optimize Electric Vehicle (EV) charging operations. Whether you're an admin, operator, or station owner, Eco provides a comprehensive interface to streamline EV charger networks efficiently.

---

## 🌍 Purpose

The **Eco Web Portal** aims to empower EV infrastructure stakeholders with the tools to:

- 📈 Monitor real-time charger performance
- 🔌 Track and control charger sessions
- 📍 Manage charger locations and station details
- 🧾 View session history and generate reports
- 👥 Manage users, roles, and permissions
- 📊 Analyze usage statistics with interactive dashboards

---

## 🔑 Key Features

| Feature | Description |
|--------|-------------|
| 📡 **Live Monitoring** | Monitor charger health, availability, and session activity in real time |
| 🗺️ **Station Map** | Visual overview of all stations with geolocation support |
| ⚙️ **Charger Management** | Add, update, or deactivate chargers and their configurations |
| 📊 **Analytics Dashboard** | Powerful insights on usage trends, session durations, and energy delivered |
| 🧑‍💼 **Role-Based Access** | Admin, Operator, and Viewer roles with specific permissions |
| 📤 **Reports & Exports** | Export data to CSV, PDF or directly send via email |
| 🔔 **Alerts & Notifications** | Set thresholds and get alerted on charger errors or usage milestones |
